# Publish to GitHub

1. Create a public repository named `cyberdyne-systems-risk-register`.
2. Upload the contents of this folder (not the enclosing ZIP) to the repository root.
3. Confirm the workbook is in `deliverables/` and preview `README.md`.
4. Suggested description: `GRC portfolio project: 24-risk SaaS risk register with treatment plans and NIST CSF 2.0, CIS Controls v8.1, and SOC 2 mapping.`
5. Suggested topics: `grc`, `risk-management`, `nist-csf`, `cis-controls`, `soc2`, `cybersecurity`, `portfolio-project`.

Do not publish real customer data, secrets, internal company information, or unsupported claims that controls were implemented or tested.
